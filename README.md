# GPS to Tablet (Android App)

Легковесное Android-приложение для трансляции GPS-координат со смартфона на планшет в Яндекс.Карты.

## Как собрать APK через GitHub Actions (бесплатно, без Android Studio):

1. Создайте новый публичный или приватный репозиторий на [GitHub.com](https://github.com/new).
2. Загрузите все файлы из этой папки (`android_project`) в созданный репозиторий (обязательно включая `gradle.properties` и папку `.github`).
3. Перейдите во вкладку **Actions** в вашем репозитории на GitHub.
4. Вы увидите запущенный процесс сборки `Build Android APK`.
5. Через 1–2 минуты сборка завершится зеленой галочкой. Нажмите на неё и в блоке **Artifacts** скачайте готовый файл **`GPS-to-Tablet-APK`** (внутри будет `app-debug.apk`).
6. Установите `app-debug.apk` на смартфон.

## Промпт для нейросетей (ChatGPT / Claude / Cursor / v0)

Если вы хотите создать альтернативное приложение или доработать проект через ИИ, используйте следующий готовый промпт:

```text
Создай легковесный проект Android приложения на Kotlin под Android 14+ (minSdk 26, targetSdk 34) со сборкой через GitHub Actions (.github/workflows/build.yml).
Задача приложения:
1. Иметь Foreground Service с уведомлением ("Трансляция GPS на планшет") и типом location.
2. Получать геопозицию через LocationManager (GPS_PROVIDER) с частотой раз в 1 секунду.
3. Иметь поле ввода IP-адреса планшета (сохранять в SharedPreferences) и кнопку "Старт/Стоп".
4. Отправлять каждую секунду координаты на планшет через HTTP POST запрос по адресу http://<IP>:8088/api/gps с телом JSON:
   {"lat": 55.75, "lng": 37.61, "accuracy": 5.0, "speed": 10.5, "bearing": 180.0}
5. Без тяжелых библиотек (чистый Android SDK или Core KTX), чтобы проект быстро и безошибочно собирался в GitHub Actions на ubuntu-latest без необходимости локальной установки Android Studio.
```
